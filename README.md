1)
Программа ищет примерное решение нелинейного уравнения. Она шаг за шагом сужает диапазон поиска, пока не достигнет нужной точности, а затем выводит найденный ответ.

2)
Сначала задаются границы отрезка и требуемая точность вычислений. Потом программа проверяет, нужно ли продолжать расчёт. Для этого она смотрит, в какой половине отрезка находится корень — для этого сравнивает знаки значений функции на краях и в середине.

Если произведение значений функции на левом краю и в середине меньше или равно нулю, значит, корень в левой половине — тогда правую границу сдвигают к середине. Если нет — корень в правой половине, и левую границу сдвигают к середине.

Расчёты идут, пока выполняется условие точности; как только оно перестаёт выполняться, вычисления останавливаются.
